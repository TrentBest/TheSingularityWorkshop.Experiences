The architecture

Different doors. Same Experience.

Shared identity does not mean shared implementation. Every manifestation keeps its own strengths, constraints, and trust boundary.

Follow the identity, not the window.

The browser can discover an Experience and request that AnyApp open it. AnyApp resolves an immutable identity, verifies the artifact, and composes it locally. A VR client can participate without inheriting the browser's or desktop's implementation.

  • WebApp distributes, discovers, visualizes, and interacts.
  • AnyApp supplies local resources, persistence, and heavier computation.
  • VR focuses on tracking, rendering, input, and latency-sensitive work.

The immutable seam

Identity before execution.

The repository stores and verifies opaque bytes. Composition belongs to the host. These responsibilities stay separate.

01 / Declare

A manifest describes the composition closure: bundle IDs, artifact versions, content hashes, and optional configuration.

02 / Verify

Resolve the immutable artifact address and verify the bytes before materialization. A name alone is not identity.

03 / Compose

The host materializes verified artifacts and binds them to the composition runtime. Storage does not become an execution engine.
